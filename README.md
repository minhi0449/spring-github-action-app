# 📝 spring-github-action-app

Spring Boot 기반의 **게시판 애플리케이션**으로,  
**GitHub Actions**를 활용하여 **CI/CD 파이프라인**을 구축하는 프로젝트입니다.

---

## 📌 주요 기능

✅ **Spring Boot** 기반의 게시판 애플리케이션 개발  
✅ **GitHub Actions**를 활용한 CI/CD 파이프라인 구축  

---

## 🛠 기술 스택

| 기술  | 설명 |
|-------|-----------------------------|
| **Spring Boot** | 백엔드 프레임워크 |
| **GitHub Actions** | CI/CD 자동화 |
